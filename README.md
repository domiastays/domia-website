# Domia Stays — website
Static site for Domia Stays Group S.L. (Benidorm / Costa Blanca).
Plain HTML/CSS/JS — no build step. Open `index.html` or host the folder as-is.

## Deploy
- **Netlify Drop:** drag this folder onto https://app.netlify.com/drop
- **GitHub Pages:** push this repo, then Settings → Pages → deploy from branch `main` (root)
- **Cloudflare Pages:** upload this folder

Assets in `/assets`, styles in `/css/styles.css`, interactions in `/js/script.js`.
